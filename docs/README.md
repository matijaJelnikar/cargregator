# Cargregator

Set your car search filters once, pick which sites to include, and search them all with one tap.
Like Skyscanner, but for used cars across Europe (starting with Slovenia and its neighbours).

**Legal approach:** Cargregator does not scrape or copy listings. It translates the user's filters
into each site's own search link and opens the site's own results page. Listing data comes later,
only from dealer feeds and partnerships.
