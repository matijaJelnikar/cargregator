# Backfill missing car generations

The registration-led catalogue omits pre-2011 generations even when their model exists, including Subaru Legacy IV. Audit the missing-car backlog and supplement it with source-backed European catalogue facts and bilingual reports.

Start with one directly researched Legacy IV pilot, prepared as local SQL for Matija to insert. Continue further report writing only after he compares its texts with the existing Sonnet content.

Out of scope: a bulk database load, deployment, new photo hosting, changing the report display, a complete worldwide historical catalogue, and US/Japanese-only variants. Supabase writes remain Matija's action unless separately authorised.
